# FakeDet
Project for IS460.

An AI-driven assistant designed to detect and analyze fake news and manipulated media content circulating on social platforms. Utilizing data mining (DM), machine learning (ML), 
deep learning (DL), and large language models (LLMs), it evaluates text, images and audio identify misinformation, deepfakes, and synthetic media, helping users, platforms,
and fact-checkers maintain information integrity.
